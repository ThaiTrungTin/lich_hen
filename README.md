# Lịch Hẹn 💕

Một trang web rủ đi chơi / đi cà phê với hiệu ứng troll nút "Không đồng ý" chạy trốn liên tục cực kỳ dễ thương và hài hước!

## ✨ Tính năng nổi bật
- **Giao diện tông hồng cute & ấm áp**: Thiết kế ngọt ngào, hiện đại, chuẩn responsive trên cả điện thoại di động và máy tính.
- **Nút troll chạy trốn**: Khi di chuột hoặc chạm tay vào nút "Không đi đâu", nút sẽ liên tục nhảy né tránh đến các vị trí ngẫu nhiên, không thể bấm trúng.
- **Nút "Đi lunn nè!" phồng to**: Mỗi lần bấm trượt nút từ chối, nút đồng ý sẽ to dần lên.
- **Nhạc nền Lofi lãng mạn**: Tự động phát âm thanh du dương bằng Web Audio API không phụ thuộc mạng.
- **Hiệu ứng chúc mừng rực rỡ**: Pháo hoa giấy (confetti) và màn hình chốt kèo siêu đáng yêu khi bấm đồng ý.

## 🚀 Cách chạy trên máy cá nhân
Chỉ cần mở file `index.html` trực tiếp trên trình duyệt, hoặc dùng một live server bất kỳ (như Live Server trên VS Code hoặc `npx serve .`).
